# 用户指南

这份文档只讲“拿到客户端之后怎么用”。不需要服务器地址、不需要配置文件、不需要命令行。

## 1. 打开

双击 `NacViewer.exe`。等一两秒，会出现一个叫 `nac` 的窗口。

- 第一次运行 Windows 可能提示“未知发布者”：这是未签名程序的正常提示。
  点“更多信息” → “仍要运行”即可。
- 不需要安装，不需要联网注册，不需要填任何地址。

## 2. 看页面

打开后默认在第一页。窗口上方是地址栏，只显示页码：

| 输入 | 去哪 |
|---|---|
| `/1` 或 `1` | 第 1 页 |
| `/7` | 第 7 页 |
| `/` | 首页 |
| `console/1` | 仅站长使用，普通用户可忽略 |

页面里的链接直接点；`Esc` 或 `Alt+←` 返回，`Alt+→` 前进，`F5`/`R` 刷新。
`Ctrl+L` 可以定位到地址栏。

## 3. 表单

有的页面有输入框和按钮。填好后点按钮提交，结果会刷新在当前页。
表单内容会随页面提交到服务器；公开站点的内容可能被其他人看到，不要填敏感信息。

## 4. 常见问题

**窗口打不开 / 闪退**
先确认是 Windows 10/11 64 位；把 exe 放在普通文件夹（如下载目录），不要放在压缩包里直接运行。

**提示“无法连接”**
服务器可能暂时不可用，或当前网络挡住了 7000 端口。稍后再试；持续失败请联系站长。

**页面空白**
按 `F5` 刷新；还不行就联系站长，不要自己改配置。

**SmartScreen 拦截**
点“更多信息” → “仍要运行”。如果系统策略完全禁止未知程序，需要管理员放行。

**我能自己填服务器地址吗？**
不能，也不需要。地址栏只接受页码；服务器地址是编译进客户端的。

**管理后台在哪？**
不在用户客户端里。运营台是站长的工具，通过 SSH 隧道访问，普通用户不需要。
