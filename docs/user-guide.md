# 使用手册

给拿到 `NacViewer.exe` 的人。不需要装任何东西，也不需要配置文件 ——
服务器地址和证书指纹都已经在程序里。

---

## 1. 打开

双击。第一次运行时 Windows 可能弹 SmartScreen：点「更多信息」→「仍要运行」。

打开的窗口从上到下四层：

```
[ 标签页 ]              ← 现在开着哪几个页面
[ ← → ⟳ ⌂   地址栏 ]    ← 手里要按的东西
（页面内容）
[ 状态栏 ]              ← 连上没有、当前地址、标签数
```

## 2. 地址栏

地址 = **名字** + 路径。名字就是一整串字符，不是"域名 + 后缀"：

| 输入 | 去哪 |
|---|---|
| `/`、空 | 当前站首页 |
| `/about`、`about` | 当前站的这一页 |
| `nac.local/` | 主站首页 |
| `iris.out/entry/blue` | 另一个站的某一页 |
| `EX_MYTH/myth/3` | 同上；名字里有下划线也没关系 |

- 表里没有的名字会自动去问当前服务器，不用你操心它在哪台机器上
- **不用也输不进 IP 或端口**：粘一个 `1.2.3.4:7000/` 会被拒绝，那不是地址
- 大小写无所谓：敲 `ex_myth` 也能进，地址栏会换成服务器用的写法
- 目录要看目录里有没有 `index.py`；没有就 404，不会自动列内容

三个键管地址栏：`Ctrl+L` 跳进去并**全选**（直接覆盖旧地址），
`Enter` 打开，`Esc` 放弃并还原。

## 3. 标签页

| 操作 | 怎么做 |
|---|---|
| 新标签页 | `Ctrl+T` 或点标签栏右边的 `+` |
| 关闭 | `Ctrl+W`、点标签上的 `×`、或中键点标签 |
| 切到下一个 | `Ctrl+Tab` |
| 切到某个 | 直接点它 |

每个标签是**独立**的：自己连自己的服务器，有自己的前进后退、图片缓存、
填了一半的表单、滚动位置。在一个标签里跳到别的站，其它标签不受影响。
只剩一个标签时关不掉 —— 窗口总得有东西画。

## 4. 其它按键

| 键 | 作用 |
|---|---|
| `Esc` / `Alt+←` | 返回（可以跨站回到上一页） |
| `Alt+→` | 前进 |
| `F5` / `R` | 刷新当前页 |
| `Ctrl+Enter` | 提交当前表单 |

页面里的链接直接点。动画（比如汉诺塔）**点一下画面就从头播**。

## 5. 出问题了

| 看到什么 | 意思 / 怎么办 |
|---|---|
| 「无法连接到服务器」 | 服务器暂时不可用，或端口被挡住了。按 `F5` 重试；一直不行就找站长 |
| 「找不到站点 xxx」 | 服务器不认识这个名字。检查拼写，或问站主要准确的名字 |
| 「404 · 没有 /xxx」 | 地址拼错了，或者那一页已经不在了 |
| 页面空白 | 按 `F5`；还空白就是页面本身出错了，找站长 |
| 「找不到站点目录 nac.routes」 | 只有本地开发版会这样（它需要配置文件）。分发给你的版本不会 |
| 双击之后什么都没发生 | 正常情况会弹一个标题为 `Nac` 的框说明原因，同一段文字在 `%TEMP%\nac-viewer-crash.txt`。**连框都没有**说明程序根本没起来，多半被杀毒拦了 |
| SmartScreen 拦截 | 「更多信息」→「仍要运行」。系统策略完全禁止未知程序时，需要管理员放行 |

## 6. 它在你电脑上留下什么

- **不写配置、不写缓存、不写历史**：所有状态都在内存里，关掉就没了
- 系统层面的常规痕迹还是有：`Prefetch`、文件来源标记（`Zone.Identifier`）
- 只有崩溃时才写一个 `%TEMP%\nac-viewer-crash.txt`
- 服务器一定看得到你的 IP —— 客户端是直连它的，这是当前传输层的取舍

## 7. 管理后台在哪

不在这里。运营台只监听服务器本机，要用 SSH 隧道 + admin 版客户端才能进，
普通分发版里连那段代码都没有。
