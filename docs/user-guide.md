# 使用手册

给拿到 `viewer.exe` 的人。

---

## 1. 打开

双击运行。不需要安装，不需要额外文件——服务器地址和证书指纹都已经在程序里。

第一次运行时 Windows 可能弹出 SmartScreen 提示：点「更多信息」→「仍要运行」。

## 2. 地址栏

窗口上方是地址栏，显示一个名字和当前页面的路径：

| 输入 | 去哪 |
|---|---|
| `nac.local/` 或 `/` | 首页 |
| `nac.local/about` 或 `/about` | 关于页 |
| `nac.local/notes/` | `notes` 目录的首页（该目录有 `index.py` 时） |
| `shop.nac.local/` | 别的站点 |

- 目录没有单独的列表页；只有目录里放了 `index.py`，访问 `目录/` 才会进入它，否则 404。
- 界面不展示页码，也不需要记页码。
- **不能也不需要**输入 IP 或端口；`nac.local` 只是显示用的后缀，不参与真实解析。
  站点在哪由服务器回答。

## 3. 标签页

地址栏上方那一行就是标签栏，和浏览器一样可以同时开好几个页面。

| 操作 | 键 |
|---|---|
| 新标签页 | `Ctrl+T`，或点标签栏右边的 `+` |
| 关闭当前标签页 | `Ctrl+W`，或点标签上的 `×` |
| 下一个标签页 | `Ctrl+Tab` |
| 切换 | 直接点标签 |

每个标签页是**独立**的：各自连自己的服务器、有自己的前进后退、自己的图片缓存、
自己填了一半的表单和滚动位置。在一个标签里跳到别的站点，另外的标签不受影响。

只有最后剩下的那个标签关不掉——窗口总得有东西画。

## 4. 其他按键

| 键 | 作用 |
|---|---|
| `Esc` / `Alt+←` | 返回（可以跨站点回到上一页） |
| `Alt+→` | 前进 |
| `F5` / `R` | 刷新当前页 |
| `Ctrl+L` | 跳到地址栏 |
| `Ctrl+Enter` | 提交当前表单 |

页面里的链接直接点。窗口底部那一行是状态栏：连接状态、当前地址、标签页数量。

## 5. 常见情况

**「无法连接到服务器」**
服务器可能暂时不可用，或当前网络挡住了端口。稍后再试；持续失败请联系站长。

**「找不到站点 shop」**
地址里的站名不在服务器认识的范围里。检查拼写，或问站主要站名。

**「找不到站点目录 nac.routes」**
这是本地开发版才会出现的提示（它需要配置文件说明连哪台服务器）。
分发给你的版本不会这样。

**「404 · 没有 /xxx」**
地址拼错了，或者那个页面已经不在。

**页面空白**
按 `F5` 刷新；还不行就联系站长，不要自己改配置。

**SmartScreen 拦截**
点「更多信息」→「仍要运行」。如果系统策略完全禁止未知程序，需要管理员放行。

**双击之后什么也没发生**
现在会弹一个标题为 `Nac` 的错误框，里面写着原因；同一段文字也写进了
`%TEMP%\nac-viewer-crash.txt`。把那段文字发过来就能定位。
（如果连框都没有，说明程序根本没启动——多半是被杀毒软件拦了。）

## 6. 它在你电脑上留下什么

- **不写配置、不写缓存、不写历史**：所有状态都在内存里，关掉就没了。
- 系统层面会有常规痕迹：`Prefetch`、文件来源标记（`Zone.Identifier`）。
- 服务器一定能看到你的 IP——客户端直接和它建立 TCP 连接，这是当前传输层的取舍。

## 7. 管理后台在哪

不在用户客户端里。运营台是站主的工具，通过 SSH 隧道访问，普通用户不需要也不应该能碰到。
