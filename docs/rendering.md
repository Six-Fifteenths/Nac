# 渲染清单：能写什么，画成什么样，以及比 HTML 少了什么

这一页回答三件事：

1. **能写什么** —— 全部可选项，一个不落
2. **画成什么样** —— 每一项的视觉效果和固定数值
3. **比 HTML 少了什么** —— 想做但做不到的事，以及为什么

配套：写作细节见 [authoring.md](authoring.md)，为什么这么设计见
[../PROTOCOL-DESIGN.md](../PROTOCOL-DESIGN.md)，一帧字节长什么样见
[how-it-works.md](how-it-works.md)。

---

## 0. 四个层，一句话一层

| 层 | 谁决定 | 写法 |
|---|---|---|
| **文字** | 页面 | Markdown（标题、粗斜体、列表、引用、代码块、分隔线、链接） |
| **结构** | 页面 | `[[指令 …]]`：表单、图片、终端、动画、盒子、分栏、页签、提示框 |
| **外观** | 页面 | 14 个「皮肤」属性：底色、描边、圆角、阴影、透明度、字体、字号、字色、对齐 |
| **布局** | **客户端** | 页面完全没有话语权：行宽 860、内边距、间距、堆叠顺序都是固定的 |

> 一句话：**页面说「这一块是什么」，客户端说「它多大、在哪」。**

## 1. 客户端固定的那些数值

写页面时这些改不了，也不需要知道，但想知道"为什么看起来是这样"时有用：

| 项 | 值 |
|---|---|
| 内容列宽 | 最宽 **860pt**，窗口更宽时居中；两边至少留 20pt |
| 正文 | 17pt，行距由字体决定 |
| 标题 | `#` 1.75×（≈30pt）、`##` 1.32×（≈22pt）、`###` 及以下 1.1×（≈19pt） |
| 段间距 | 8pt（每个段落之后） |
| 空行 | 6pt |
| 标题上/下间距 | 14pt / 6pt |
| 列表缩进 | 圆点前 12pt，`•` 后跟正文 |
| 引用 | 左边 3pt 竖线 + 6pt 缩进，字色降为正文的 62% |
| 盒子内边距 | **有底色或描边时** 14pt × 12pt（没有就为 0） |
| 页面上下留白 | 顶部 18pt、底部 60pt |
| 字体 | `sans` = Titillium Web、`serif` = PT Serif、`mono` = 系统等宽；中文一律落系统 CJK |
| 背景 | 固定的浅色（不是深色模式，也没有开关） |

## 2. 文字：Markdown 全表

写法就是 Markdown，`nac.*` 里的 `h1/p/b/i/code/...` 只是替你写这些字符。

| 写法 | 画成什么 |
|---|---|
| `# 标题` | 一级标题，30pt 粗体 |
| `## 标题` | 二级标题，22pt 粗体 |
| `### 标题` 到 `###### 标题` | 都画成三级：19pt 粗体（**只分三级样式**） |
| 普通的行 | 段落。连续几行**会合成一段**，不会换行 |
| 一个空行 | 段落之间空 6pt |
| `**粗**` / `__粗__` | 粗体 |
| `*斜*` / `_斜_` | 斜体 |
| `` `代码` `` | 等宽，浅灰底 |
| `- 项` / `* 项` / `+ 项` | 无序列表（三种圆点等价） |
| `1. 项` | 有序列表（**你写的数字被忽略**，客户端自己编号） |
| `> 引用` | 左侧竖线 + 变淡的字 |
| ` ```lang ` … ` ``` ` | 代码块，右上角标语言名 |
| `---` / `***` / `___` | 一条分隔线 |
| `[文字](/路径)` | 站内链接（同一站点的另一页） |
| `[文字](https://…)` | 站外链接，点了交给系统浏览器；**只认 http/https** |
| `[文字](31345)` | 直接写页号的链接 |
| `\*` `\_` `` \` `` `\[` | 反斜杠转义，原样显示那个字符 |

**两种行内写法都认**：

- Markdown 的 `[文字](/路径)`、`[文字](https://…)`、`[文字](页号)`
- Nac 的 `[[路径|文字]]`、`[[url:https://…|文字]]`、`[[页号|文字]]`

助手函数（`nac.inline_path` 等）现在发的是**第二种**（它是编译产物，不用手写）；
手写页面时两种都行，行为完全一样。不认的协议（`javascript:`、`file:`、自定义）
不会变成链接，会原样显示成文字。

## 3. 结构：`[[指令]]` 全表

Markdown 表达不了的东西才用指令。**一条指令占一整行。**

### 3.1 媒体

| 指令 | 说明 |
|---|---|
| `!img 图号 宽度% WxH` | 图片。图号是发布时分配的；宽度是百分比；`WxH` 让客户端提前按比例留位 |
| `!cap 文字` | 图片下面的小字说明 |
| `[[avatar 名字 尺寸]]` | 头像：名字算颜色、首字母上图。不联网、不读文件 |
| `[[scene 宽x高 秒]] … [[end]]` | 一块动画画布，里面用 `[[bar 颜色 宽 高]]` + `[[at 秒 x y]]` 定义关键帧 |

`nac.img()` / `nac.figure()` / `nac.avatar()` / `nac.scene()` 都是它们的包装。

### 3.2 表单（一页只能有一个）

| 指令 | 说明 |
|---|---|
| `[[form 页号]]` | 表单目标。**一页只认最后一个**，所以一次只能提交一件事 |
| `[[input 名\|标签]]` / `[[password …]]` | 单行输入 / 密码 |
| `[[textarea 名\|标签]]` | 多行 |
| `[[select 名\|标签\|甲;乙;丙]]` | 下拉 |
| `[[check 名\|标签]]` | 勾选 |
| `[[hidden 名\|值]]` | 读者看不见的状态 |
| `[[prefill 名\|值]]` | 初始值，只在读者没动过时生效 |
| `[[button 文字]]` | 提交按钮。点了 = 整页重新请求 |

### 3.3 版面结构

| 指令 | 说明 |
|---|---|
| `[[table]] … [[end]]` | 表格：每行 `\| 单元格 \| 单元格 \|`，**第一行当表头** |
| `[[note 类型\|标题]] … [[end]]` | 提示框，类型是 `info` `ok` `warn` `danger`（四种颜色） |
| `[[details 标题]] … [[end]]` | 折叠块，默认收起 |
| `[[tabs 甲;乙]] … [[tab]] … [[end]]` | 页签，点标题切换 |
| `[[cols n]] … [[col]] … [[end]]` | 并排 n 栏，**宽度客户端平分** |
| `[[box …]] … [[end]]` | 盒子：只负责皮肤（底色/描边/圆角/阴影），不负责尺寸 |
| `[[sheet]] .名字 { 属性 } [[end]]` | 整页样式表，一行一条规则 |
| `[[term panel\|标题\|页号]] … [[end]]` | 终端面板（带标题条和外框） |
| `[[term bare]] … [[end]]` | 终端面板（黑底、无边框、无标题条） |

## 4. 外观：14 个皮肤属性

写在 `[[box …]]` 里，或者写成 `[[sheet]]` 规则给类名用。**一个都不涉及尺寸和位置。**

| 属性 | 值 | 效果 |
|---|---|---|
| `class` | 名字 | 从样式表取一条规则 |
| `bg` | `#rgb` `#rrggbb` `#rrggbbaa` `white` `black` | 底色 |
| `color` | 同上 | 文字色（子块继承） |
| `border` | `1:#dddddd` | 描边：线宽:颜色 |
| `radius` | `4` | 圆角 |
| `shadow` | `8` / `8,2` / `8,2:#0000001f` | 阴影：模糊[,向下偏移][:颜色] |
| `opacity` | `0.6` 或 `60` | 整块透明度 |
| `ta` | `left` `center` `right` | 盒子内**文字**对齐 |
| `size` | `16` 或 `16px` | 字号（继承） |
| `weight` | `bold` / `normal` | 字重（继承） |
| `font` | `sans` `serif` `mono` | 字体族（继承） |
| `italic` | `1` | 斜体（继承） |
| `link` | `#5cb85c` | 盒子内链接的颜色（继承） |
| `nowrap` | `1` | 不折行 |

数值只收 `16` 和 `16px`。`50%`、`calc(...)`、`2em` 会被当成没写 —— 它只收数字。

## 5. 比 HTML/CSS 少了什么

分四档。**A 档是换种写法就能做到，B 档只能做到近似，C 档必须改客户端，D 档是刻意永不做。**

### A. 换种写法就能做到

| 想干的事 | HTML 里 | 这里怎么写 |
|---|---|---|
| 标题分级 | `<h1>`…`<h6>` | `#`…`######`（样式只有三级） |
| 粗体 / 斜体 / 行内代码 | `<strong>` `<em>` `<code>` | `**x**` `*x*` `` `x` `` |
| 列表 | `<ul>`/`<ol>` | `- ` / `1. ` |
| 引用 | `<blockquote>` | `> ` |
| 代码块 | `<pre><code class="lang">` | ` ```lang ` … ` ``` ` |
| 表格 | `<table>` | `[[table]]` + `\| 单元格 \|` |
| 分隔线 | `<hr>` | `---` |
| 站内链接 | `<a href="/x">` | `[文字](/x)` |
| 站外链接 | `<a href="http…">` | `[文字](https://…)` |
| 提示框 | `<div class="alert">` | `[[note warn\|标题]]` |
| 折叠 | `<details>` | `[[details 标题]]` |
| 页签 | JS + CSS | `[[tabs 甲;乙]]` |
| 分栏 | `display:grid` | `[[cols n]]`（平分） |
| 按下标切换内容 | JS | 无 —— 改成各自一页 |
| 表单 | `<form>` | `[[form 页号]]` + 字段指令 |

### B. 只能做到近似（本质是"没有布局引擎"）

| 想干的事 | HTML/CSS 里 | 这里 |
|---|---|---|
| 指定宽度 | `width: 600px` / `60%` | **不行**。内容列固定 860pt 上限 |
| 自己排版 | `flex` `grid` `float` `position` | **不行**。盒子只能上下堆叠 |
| 控制间距 | `margin` `padding` `gap` | **不行**。内边距、段间距是客户端定的 |
| 多栏比例 | `grid-template-columns: 2fr 1fr` | 只有**等分**，没有比例 |
| 响应式重排 | `@media (max-width:600px)` | 不需要，也不能：只有一种版式 |
| 自定义字体 | `@font-face` + 字体文件 | 只有三族，编在客户端里 |
| 渐变 / 多重背景 | `linear-gradient(...)` | 只有单色底 |
| 阴影自由调 | `box-shadow: 0 2px 8px rgba(...)` | `shadow: 8,2:#0000001f`，够用但只有一层 |
| 圆角任意 | `border-radius: 50%` | 只有整数像素 |
| 表格样式 | 斑马纹、合并单元格 | 只有一种样式，不能合并单元格 |
| 图片尺寸 | `width` / `object-fit` | 只有百分比宽度，保持原比例 |
| 内联图片 | `<img>` 混在段落里 | **不行**，图片只能自己占一块 |

### C. 必须改客户端才可能（不是页面能力问题）

| 想干的事 | 现状 |
|---|---|
| 整页铺满（没有 860 上限、没有留白） | 需要页面头一个 `# nac:fullbleed`，客户端跳过阅读版式 |
| 深色主题 / 换肤 | 客户端现在是固定浅色 |
| 局部刷新（点一下只换一块） | 协议要加一种请求，客户端要能就地替换 |
| 页面自己写逻辑给客户端跑 | 客户端现在只会执行"折叠/页签"这两个内置交互 |
| 单页超过 16KB / 超过 ~400 页 | 协议上限：正文 ≤16KB，清单受 32KB 帧限制 |
| 站外图片 / 任何外链资源 | 图片必须发布时打包，样式表不能发请求 |

### D. 刻意永不做

| 想干的事 | 为什么 |
|---|---|
| `<script>` / 事件回调 | 客户端没有脚本引擎，也不打算有。逻辑在服务端的 Python 里 |
| 选择器（后代/相邻/属性/伪类） | 类名一层哈希查找；加选择器就要加层叠，加层叠就要加特异性…… |
| `::before` / `::after` + `content` | 样式表能造内容 = 一个没日志、没超时的第二套模板语言 |
| `position` `float` `z-index` `overflow` | 布局引擎的入口 |
| `@media` `@container` `calc()` `CSS 变量` | 前两个是分支，后两个是表达式 |
| `@keyframes` / `transition` | 动画只走 `[[scene]]`（数据驱动的时间轴），样式不管时序 |
| 音视频 / iframe / canvas / SVG | 客户端不解析，也没有插件机制 |
| 打印样式 / 分页 | 输出目标是窗口，不是纸 |

## 6. 规模与性能限制

| 限制 | 数值 |
|---|---|
| 一页正文 | ≤ 16384 字节（`CHUNK`） |
| 页面脚本 stdout | ≤ 128 KB |
| 页面执行时间 | 2 秒（超时 kill） |
| 单站页面数 | 实测 ~400 页（清单受 32768 字节帧限制） |
| 并发 | 32 |
| 一页表单 | 1 个提交目标 |
| 一次点击 | 一次完整请求（没有局部刷新、没有推送） |

## 7. 想确认"到底长什么样"

最快的办法不是看文档，是开客户端看现成的页面：

| 想看什么 | 地址 |
|---|---|
| 全套排版示例（列表、表格、提示框、页签、折叠） | `nac.local/layout` |
| 分栏的极限 | `nac.local/features` |
| 终端面板（带外框 / 裸模式） | `web.shell` |
| 一个真的多页应用（表单、会话、SQLite、分页） | `conduit.sh` |
| 动画时间轴 | `nac.local/hanoi` |
