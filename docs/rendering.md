# 一个站点能做的全部事情

这一页是**唯一的能力清单**。写页面时想「这件事能不能做」，只查这里。

- 想从零开始写第一页：[start-here.md](start-here.md)
- 想看它是怎么运作的：[how-it-works.md](how-it-works.md)
- 想查函数签名与逐条说明：[authoring.md](authoring.md)

---

## 0. 一句话：只有十二件事

一个站点能做的事，全部落在这十二类里。**没有第十三件。**

| # | 能力 | 页面侧 | 客户端画什么 |
|---|---|---|---|
| 1 | 写文字 | `p` `h1` `h2` `h3`，或者 Markdown | 段落、三级标题 |
| 2 | 排列表 | `quote` `bullets` `ordered` `table` `code` `hr` | 引用、列表、表格、代码块、分隔线 |
| 3 | 分区 | `box` `cols` `col` `note` `details` `tabs` | 盒子、分栏、提示框、折叠、页签 |
| 4 | 放图和附件 | `img` `figure` `cap` `avatar` `file` | 图片、说明、头像、一行「附件 · 保存」 |
| 5 | 放会动的东西 | `raw("[[scene …]]")` | 一块矩形画布 + 时间轴 |
| 6 | 放终端 | `term` `term_line` `term_ascii` … | 终端面板 |
| 7 | 让读者填 | `form_path` `field` `textarea` `check` `hidden` `prefill` `button` | 表单七件套 |
| 8 | 读这次请求 | `path` `path_arg` `field_of` `submitted` `checked` `page_id` | — |
| 9 | 记住这位读者 | `session_get` `session_set` `session_pop` `flash` `flashes` | — |
| 10 | 存站点数据 | `db` `read_json` `write_json` `read_lines` `append_line` `counter` | — |
| 11 | 放链接与跳转 | `link_path` `inline_path` `inline_url` `nav` `redirect_path` | 块级链接、行内链接、站外链接 |
| 12 | 说明这一页 | 文件头的 `# nac:` 四行 | 窗口标题、地址、清单、静态化 |

页面侧一共 82 个函数名、28 种块、25 条指令。但**它们只是这十二件事的不同写法**，
不是十二件事之外的新东西。

`nac` 底下分了十组（`text` `links` `skin` `media` `forms` `req` `state` `data` `site` `flow`），
就是为了让「这一段在干什么」一眼看得出来：

```python
nac.text.p("正文")
nac.forms.field("title", "标题")
if nac.req.submitted(): ...
nac.state.session_set("uid", 7)
```

## 1. 写文字

写法有两条路，效果完全一样。**手写页面建议直接用 Markdown**：

| Markdown | 辅助函数 | 画成什么 |
|---|---|---|
| `# 标题` | `nac.h1()` | 30pt 粗体 |
| `## 标题` | `nac.h2()` | 22pt 粗体 |
| `###` 到 `######` | `nac.h3()` | 都画成 19pt 粗体（**只分三级**） |
| 一行普通文字 | `nac.p()` | 段落。连续几行会合并成一段 |
| 空行 | `nac.gap()` | 段间空 6pt |
| `**粗**` / `__粗__` | `nac.b()` | 粗体 |
| `*斜*` / `_斜_` | `nac.i()` | 斜体 |
| `` `代码` `` | `nac.tt()` | 等宽，浅灰底 |
| `\*` | `nac.esc()` | 转义，把标记变成字面文字 |
| 整段 Markdown | `nac.write()` | 原样交给客户端解析 |

`nac.join(*parts)` 只是把几段拼成一段再交给 `p`，省一层括号。

## 2. 排列表

| 写法 | 画成什么 |
|---|---|
| `- 项` / `* 项` / `+ 项`，或 `nac.bullets(...)` | 无序列表，`•` 在前 |
| `1. 项`，或 `nac.ordered(...)` | 有序列表，**你写的数字被忽略**，客户端重编号 |
| `> 引用`，或 `nac.quote(...)` | 左侧竖线 + 变淡的字 |
| ` ```lang ` … ` ``` `，或 `nac.code(text, lang=)` | 代码块，右上角标语言名 |
| `---` / `***` / `___`，或 `nac.hr()` | 一条分隔线 |
| `nac.table(表头元组, 行列表)` | 表格，第一行是表头 |

嵌套规则：表格的单元格**只放文字和行内样式**（粗体、等宽、链接），
放不进列表、提示框、图片。其它容器没有这个限制。

---

## 3. 分区

五种容器，都能装任意块，嵌套深度不限。

| 写法 | 画成什么 |
|---|---|
| `with nac.box("类名", **属性)` | 一个带皮肤（底色/描边/圆角/阴影）的盒子 |
| `with nac.cols(n):` + `nac.col()` | 并排 n 栏，**每栏宽度客户端平分** |
| `with nac.note("info"/"ok"/"warn"/"danger", "标题"):` | 四种颜色的提示框 |
| `with nac.details("标题"):` | 折叠块，默认收起 |
| `with nac.tabs("甲", "乙"):` + `nac.tab()` | 页签，选中状态客户端记住 |

`nac.box()` 的皮肤属性只有 14 个，全是颜色和字，**没有一个涉及尺寸和位置**：

`class` `bg` `color` `border` `radius` `shadow` `opacity`
`ta` `size` `weight` `font` `italic` `link` `nowrap`

配合 `nac.sheet("…")` 可以把这些写成类名：一页一张表，一行一条规则。

## 4. 放图和附件

| 写法 | 画成什么 |
|---|---|
| `nac.img("img/x.png", 100)` | 一张图，宽度是内容列的百分比 |
| `nac.figure(path, 说明, 100)` | 图 + 下面一行小字说明 |
| `nac.cap("说明")` | 单独一行小字 |
| `nac.avatar("名字", 28)` | 头像：名字算颜色、首字母上图，**不联网不读文件** |
| `nac.file("钥匙.zip")` | 一行「文件名 · 大小 · 保存」，点了存进下载目录 |

图片必须放在站点目录里，发布时打包；**样式表不能发请求，页面也不能引外链图片**。
发布时只剪掉元数据段，像素逐位不变。

附件放在站点目录的 `_files/` 下（平铺，不放子目录，每个不超过 2 MB），页面上写
`nac.file("钥匙.zip")`。读者点「保存」客户端才去取字节，取到就写进系统下载目录：

- 名字由客户端净化：路径分隔符、控制字符全削掉，`..`、`CON` 这类名字绕开；
- 重名不覆盖，自动变成 `钥匙 (2).zip`；
- **可以反复点**：想再存一份就再点一次；
- 页面说不出路径。它只能给一个名字，落到哪里由客户端决定。

发布时 `_files/` 里的文件同时也会复制进 `scripts/`，所以页面自己也能
`open("_files/钥匙.txt")` 读它——附件和站点自己的数据是同一份。

## 5. 放会动的东西

只有一种：`[[scene 宽x高 秒]]`，里面用 `[[bar 颜色 宽 高]]` 定义矩形、
`[[at 秒 x y]]` 定义关键帧。客户端按时间轴插值、60 帧，**服务端只被请求一次**。

```python
nac.raw("[[scene 540x300 6.0]]")
nac.raw("[[bar 74bf2e 54 120]]")
nac.raw("[[at 0 400 -20]]")
nac.raw("[[at 6 -80 -20]]")       # 六秒内从右飘到左
nac.raw("[[end]]")
```

只能画**纯色圆角矩形**。没有贴图、没有旋转、没有像素缓冲。

## 6. 放终端

```python
with nac.term("WebShell", target=nac.page_id()):
    nac.term_ascii(["██╗", "██║"])
    nac.term_line(("in", "$ "), ("out", "hello"))
    nac.term_cursor("cmd")
```

- `panel`（默认）：黑底 + 标题条 + 外框，像一块终端窗口
- `bare`：黑底、无框无标题条，适合整页做成一个 shell

## 7. 让读者填

一页可以放**多个**表单：`nac.form_path()` 之后的字段属于它。

| 写法 | 画成什么 |
|---|---|
| `nac.form_path("/save")` | 声明表单提交到哪个地址 |
| `nac.field(名, 标签)` | 单行输入；`nac.password()` 是打了码的 |
| `nac.textarea(名, 标签)` | 多行输入 |
| `nac.check(名, 标签)` | 勾选 |
| `nac.hidden(名, 值)` | 读者看不见的状态 |
| `nac.prefill(名, 值)` | 初始值，只在读者没动过时生效 |
| `nac.button("文字")` | 提交按钮。点了 = **整页重新请求** |

两条要知道的：

- **字段名是全页唯一的**。两个表单里都叫 `title` 会互相覆盖。
- **提交时会带上全页所有字段**，服务端分不出是哪个表单按的。
  要区分就在每个表单里塞一个不同的 `hidden`。

## 8. 读这次请求

| 写法 | 拿到什么 |
|---|---|
| `nac.path()` | 这次请求的完整地址，例如 `/article/hello` |
| `nac.path_arg("/article/")` | 去掉前缀后的部分，用来认领一族地址 |
| `nac.field_of(名)` | 某个字段的值 |
| `nac.submitted()` | 这次是不是提交 |
| `nac.checked(名)` | 复选框是否勾上 |
| `nac.page_id()` | 这一页的页号 |
| `nac.request()` / `nac.fields()` | 原始请求字典 / 全部字段 |

**没有查询串**。参数只能编进路径（`/home/2`），这是地址模型的直接后果。

## 9. 记住这位读者

会话跟着**连接**走，不是跟着站点走 —— 同一个站开两个标签页就是两份会话。

| 写法 | 作用 |
|---|---|
| `nac.session_get(键, 默认)` | 读 |
| `nac.session_set(键, 值)` | 写 |
| `nac.session_pop(键, 默认)` | 读并删除 |
| `nac.flash("消息")` / `nac.flashes()` | 一次性提示，读过就没了 |

## 10. 存站点数据

数据存在站点的私有目录里，跨版本保留。

| 写法 | 作用 |
|---|---|
| `nac.db()` | 打开站点的 SQLite（`appdata/site.db`） |
| `nac.read_json` / `write_json` / `update_json` | JSON 文件 |
| `nac.read_lines` / `append_line` | 纯文本行 |
| `nac.counter("名字.json")` | 计数器，原子自增 |
| `nac.data_dir()` / `nac.data_path(名)` | 数据目录本身 |

**没有删除、没有列目录**。要那些就直接 `import os` —— 页面本来就是 Python 程序，
再包一层函数只会多一个入口。

## 11. 放链接与跳转

| 写法 | 效果 |
|---|---|
| `nac.link_path("/tour", "文字")` | 单独一行的链接 |
| `nac.inline_path("/tour", "文字")` | 句子中间的链接 |
| `nac.inline_url("https://…", "文字")` | 站外链接，交给系统浏览器（只认 http/https） |
| `nac.nav("/", "/tour", "/about")` | 一行面包屑 |
| `nac.redirect_path("/tour")` | 直接跳走，不显示这一页 |

Markdown 写法等价：`[文字](/tour)`、`[文字](https://…)`、`[文字](页号)`。
不认的协议（`javascript:`、`file:`）不会变成链接，原样显示成文字。

## 12. 说明这一页

文件头四行，发布时读取：

| 行 | 作用 |
|---|---|
| `# nac:title 文字` | 窗口标题、清单里的名字 |
| `# nac:path /自定义` | 改地址（默认按文件名推） |
| `# nac:match /item/` | 认领一族地址，自己从 `path_arg` 取参数 |
| `# nac:static` | 发布时渲染一次，访问时连 Python 都不启动 |

`nac.pages()` 拿到本代所有页面的 `(页号, 路径, 标题)`；
`nac.PAGES` / `nac.IMAGES` / `nac.GEN` 是同一批信息里的常量。

**窗口标题 = 正文里第一个标题**（`# …` 或 `nac.h1()`），嵌套在盒子里也认；
正文没有标题时，才退回 `# nac:title` 那一行。所以一页认领一族地址时，
标题跟着内容走，不需要额外做什么。

## 13. 比 HTML/CSS 少了什么

### A. 换种写法就能做到

标题分级、粗斜体、列表、引用、代码块、表格、分隔线、链接、提示框、
折叠、页签、分栏、表单 —— 见上面各节。

### B. 只能做到近似（本质是「没有布局引擎」）

| 想干的事 | 这里 |
|---|---|
| 指定宽度 | **不行**。内容列最宽 860pt |
| `flex` / `grid` / `float` / `position` | **不行**。盒子只能上下堆叠 |
| 控制间距 | **不行**。内边距、段间距是客户端定的 |
| 多栏比例 2:1 | 只有**等分** |
| `@media` 响应式 | 不需要，也不能：只有一种版式 |
| 自定义字体 | 只有 `sans` / `serif` / `mono` 三族 |
| 渐变 / 多重背景 | 只有单色底 |
| 合并单元格 | 不行 |
| 段落里的行内图片 | 不行，图片自己占一块 |

### C. 必须改客户端 / 协议才可能

| 想干的事 | 缺什么 |
|---|---|
| ~~页面自己改窗口标题~~ | **已能**：正文第一个标题就是窗口标题 |
| ~~区分「这一页不存在」和「页面崩了」~~ | **已能**：空响应带原因，客户端分开说 |
| 整页铺满（去掉 860 上限和留白） | 需要一个 `# nac:fullbleed` 头 |
| 深色主题 | 客户端固定浅色 |
| 局部刷新 | 协议要加一种请求 |
| 上传文件 | 协议 `SUBMIT` 只带字符串，客户端也没有选文件的控件 |
| 场景里贴精灵图 | 客户端不会合成图块 |
| 单页 > 16KB / 单站 > ~400 页 | 协议上限 |

### D. 刻意永不做

| 想干的事 | 为什么 |
|---|---|
| `<script>` / 事件回调 | 客户端没有脚本引擎，也不打算有 |
| 选择器、层叠、`!important`、CSS 变量 | 类名一层哈希查找，加选择器就要加层叠 |
| `::before` / `::after` + `content` | 样式表能造内容 = 第二套没日志的模板语言 |
| `@keyframes` / `transition` | 动画只走 `[[scene]]`（数据驱动） |
| 音视频 / iframe / canvas / SVG | 不解析，也没有插件机制 |

## 14. 规模与限制

| 限制 | 数值 |
|---|---|
| 一页正文 | ≤ 16384 字节 |
| 页面脚本输出 | ≤ 128 KB |
| 页面执行时间 | 2 秒 |
| 单个附件 | ≤ 2 MB，必须是 `_files/` 下的单个文件 |
| 单站页面数 | 实测 ~400 页 |
| 并发 | 32 |
| 一次点击 | 一次完整请求（没有局部刷新、没有推送） |
| 连续跳转 | 服务端只跟**一次**重定向，第二次当环 |
| 空响应的原因 | `Missing`（没有这一页）/ `Failed`（崩了、超时、超上限）/ `Refused`（不认这个请求） |

## 15. 那些「看起来像能力」的东西

写页面时容易把下面这些当成平台的限制，其实它们**不是能力，是疏忽**。已经清单化了：

| 曾以为 | 实际 |
|---|---|
| 一页只能一个表单 | **错**。一页可以多个（实测过）；只有「字段名全页唯一」和「提交时带上全部字段」两条真限制 |
| 分栏最多 4 列 | 曾经写死在模板里，已去掉 |
| `nac.raw()` 里可以写 `md()` | 函数早改名成 `write()`；`raw` 的文档曾这么写，已更正 |
